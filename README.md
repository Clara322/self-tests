# self-tests
Are self tests better than random probes in aided learning?

# Hypotheses

1. A learned history predictor chooses better than fixed rules.
2. A predictor given designed self-tests chooses better than the history predictor, even after paying for the tests from the same budget.
3. Designed self-tests beat an equal number of ordinary practice attempts used as evidence.
4. The advantage of designed self-tests is largest under the unseen joint constraint.
